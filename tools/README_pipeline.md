# Как собирался `assets/models/player.glb`

Исходники — восемнадцать FBX (`source_fbx/`): шесть из пака плюс `Sprint`, `Running Jump`
и `Standing W_Briefcase Idle` (она заменила стойку из пака — `idle.fbx` больше не
используется, но оставлен в папке). Godot 4.7 умеет читать FBX напрямую,
но каждый файл стал бы отдельной сценой со своим скелетом, а анимации пришлось бы
сшивать вручную. Поэтому всё сведено в один GLB через Blender.

Порядок действий (скрипт для `blender --background --python`):

1. Импортировать `man.fbx` — меш + скелет (Mixamo-риг, 65 костей).
2. Пересобрать материал: `Principled BSDF`, в Base Color — `tripo_rgb_5d6f61d1…`
   (именно этот файл прописан внутри `man.fbx`), roughness 0.8, metallic 0.
3. Для каждого файла анимации: импортировать, забрать `Action` у временного скелета,
   переименовать (`idle.fbx` → `Idle` и т. д.), поставить fake user, удалить
   временный объект. Кости у всех файлов одинаковые, поэтому экшены ложатся на
   основной риг без ретаргета.
4. Убрать префикс `mixamorig:` у костей, у групп вершин и в путях f-кривых.
5. Убить горизонтальное root motion: у `pose.bones["Hips"].location` обнулить оси
   0 и 2 (0 = поза покоя). Именно обнулить, а не заморозить на первом кадре: у
   `Sprint` первый кадр смещён на 1.6 м — в Mixamo это разбег, — и заморозка увела
   бы тело в сторону от капсулы. Ось 1 (вертикаль) остаётся: это покачивание таза
   при шаге. У `Jump` и `RunJump` вертикаль дополнительно ослаблена до 0.4.
6. Повернуть риг так, чтобы персонаж смотрел в −Z по меркам Godot,
   отмасштабировать до роста 1.80 м, поставить ступни на пол.
7. Назначить скелету первый кадр `Idle` и экспортировать
   `export_animation_mode='ACTIONS'`, `export_rest_position_armature=False`.
8. Пост-обработкой в GLB прописать позу покоя = первый кадр `Idle`
   (TRS узлов-костей; `inverseBindMatrices` не трогаются, скиннинг не меняется).

Ключи анимаций при экспорте прорежены (`export_optimize_animation_size=True`):
18 клипов на 65 костей — это 14.5 МБ без прореживания и 6.3 МБ с ним. Пальцы и
прочие почти неподвижные кости занимали большую часть объёма.

Проверочные цифры после сборки:

* габарит меша: 1.80 м по высоте, ступни на y ≈ 0;
* таз в позе покоя: y ≈ 1.00 м, голова: y ≈ 1.56 м;
* скорости самих анимаций: ходьба **1.64 м/с**, стрейф 1.70, бег **6.05 м/с**,
  прыжок с разбега 4.85 — отсюда `walk_speed = 1.65` и `run_speed = 5.5` в `player.gd`;
* горизонтальное положение таза после чистки одинаково во всех девяти анимациях
  (проверяется в `tools/validate.gd`).
